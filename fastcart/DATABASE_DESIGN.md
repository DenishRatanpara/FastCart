## Database Design – FastCart

### 1. `users` Collection

| Field Name                 | Data Type  | Description                                      | Constraints / Notes                         |
|----------------------------|------------|--------------------------------------------------|---------------------------------------------|
| `_id`                      | ObjectId   | Primary key (user id)                            | Auto-generated by MongoDB                   |
| `name`                     | String     | Full name of the user                            | Required                                    |
| `email`                    | String     | Login email / unique identifier                  | Required, Unique                            |
| `password`                 | String     | Hashed password                                  | Optional (e.g. social login)                |
| `mobile`                   | String     | Mobile number                                    | Optional                                    |
| `role`                     | String     | `user`, `deliveryBoy`, or `admin`               | Enum, default `user`                        |
| `image`                    | String     | Profile image URL                                | Optional                                    |
| `location.type`           | String     | GeoJSON type (`"Point"`)                        | Default `"Point"`                           |
| `location.coordinates`    | [Number]   | `[longitude, latitude]`                          | Default `[0,0]`, 2dsphere index             |
| `socketId`                 | String     | Current Socket.IO connection id                  | Default `null`                              |
| `isOnline`                 | Boolean    | Whether user is online                           | Default `false`                             |
| `createdAt`                | Date       | Record creation time                             | Auto by Mongoose timestamps                 |
| `updatedAt`                | Date       | Record last update time                          | Auto by Mongoose timestamps                 |

---

### 2. `orders` Collection

| Field Name                 | Data Type            | Description                                          | Constraints / Notes                                              |
|----------------------------|----------------------|------------------------------------------------------|------------------------------------------------------------------|
| `_id`                      | ObjectId             | Primary key (order id)                               | Auto-generated                                                   |
| `user`                     | ObjectId (ref User)  | User who placed the order                            | Required, FK to `users`                                         |
| `items[].grocery`          | ObjectId             | Grocery item id                                      | FK to groceries/product collection (if defined)                 |
| `items[].name`             | String               | Item name                                            | Required                                                         |
| `items[].price`            | Number               | Price per unit                                       | Required                                                         |
| `items[].unit`             | String               | Unit (kg, pcs, etc.)                                | Required                                                         |
| `items[].image`            | String               | Product image URL                                    | Required                                                         |
| `items[].quantity`         | Number               | Quantity ordered                                     | Required, min 1                                                  |
| `isPaid`                   | Boolean              | Payment status                                       | Default `false`                                                  |
| `totalAmount`              | Number               | Total order amount                                   | Required                                                         |
| `paymentMethod`            | String               | `"cod"` or `"online"`                               | Enum, default `"cod"`                                            |
| `address.fullName`         | String               | Receiver’s name                                      | Required                                                         |
| `address.mobile`           | String               | Receiver’s mobile number                             | Required                                                         |
| `address.city`             | String               | City                                                 | Required                                                         |
| `address.state`            | String               | State                                                | Required                                                         |
| `address.pincode`          | Number               | Pincode                                              | Required                                                         |
| `address.fullAddress`      | String               | Full address text                                    | Required                                                         |
| `address.latitude`         | Number               | Latitude of delivery location                        | Optional (required for auto-assign delivery)                     |
| `address.longitude`        | Number               | Longitude of delivery location                       | Optional (required for auto-assign delivery)                     |
| `status`                   | String               | `pending`, `out_for_delivery`, `delivered`          | Enum, default `pending`                                          |
| `assignment`               | ObjectId (ref DeliveryAssignment) | Related assignment document               | Default `null`                                                   |
| `assignedDeliveryBoy`      | ObjectId (ref User)  | Delivery boy assigned                                | Default `null`                                                   |
| `createdAt`                | Date                 | Creation timestamp                                   | Auto by timestamps                                               |
| `updatedAt`                | Date                 | Last update timestamp                                | Auto by timestamps                                               |

---

### 3. `deliveryassignments` Collection

| Field Name       | Data Type                  | Description                                            | Constraints / Notes                          |
|------------------|----------------------------|--------------------------------------------------------|----------------------------------------------|
| `_id`            | ObjectId                   | Primary key (assignment id)                            | Auto-generated                               |
| `order`          | ObjectId (ref Order)       | Order to be delivered                                  | Required                                     |
| `brodcastedTo`   | [ObjectId] (ref User)      | List of delivery boys who received broadcast           | Array of deliveryBoy ids                     |
| `assignedTo`     | ObjectId (ref User)        | Delivery boy who accepted the assignment               | Nullable, set on accept                      |
| `status`         | String                     | `"brodcasted"`, `"assigned"`, `"completed"`           | Enum, default `"brodcasted"`                 |
| `acceptAt`       | Date                       | Time when assignment was accepted                      | Set on accept                                |
| `createdAt`      | Date                       | Creation timestamp                                     | Auto                                         |
| `updatedAt`      | Date                       | Last update timestamp                                  | Auto                                         |

---

### 4. `messagerooms` / `messages` Collection

| Field Name  | Data Type                 | Description                                          | Constraints / Notes                                     |
|-------------|---------------------------|------------------------------------------------------|---------------------------------------------------------|
| `_id`       | ObjectId                  | Primary key (message id)                             | Auto-generated                                          |
| `clientId`  | String                    | Client-side unique id for deduplication              | Indexed; avoids duplicate messages from socket echo    |
| `roomId`    | ObjectId (ref Order)      | Chat room id = order id                              | Required                                                |
| `senderId`  | ObjectId (ref User)       | Sender (user or delivery boy)                        | Required                                                |
| `text`      | String                    | Message content                                      | Required                                                |
| `time`      | String                    | Human readable time (e.g. `HH:MM`)                   | Optional (for display)                                  |
| `createdAt` | Date                      | Creation timestamp                                   | Auto by timestamps                                      |
| `updatedAt` | Date                      | Last update timestamp                                | Auto                                                    |

---
